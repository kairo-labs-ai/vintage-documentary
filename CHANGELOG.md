# Changelog

## 1.1.0 — 2026-11-17
- Installable as a **Claude Code plugin** (`/plugin marketplace add kairo-labs-ai/vintage-documentary`) and with `npx skills add`.
- **Vertical 9:16** films (`setup.mjs --portrait`) with titles that scale to the frame.
- New `D.quote` (attributed quote card) and `D.credits` (rolling image credits).
- Notes, wire cards and quotes are **measured**, so the camera frames them exactly.
- New `scripts/cues.mjs` (find broken cues before rendering) and `scripts/srt.mjs` (subtitles).
- Worked example `examples/deep-blue/` that Claude reads before writing its first board.
- Troubleshooting section in SKILL.md.

## 1.0.0 — 2026-11-17
- First release: evidence-board engine, typewriter labels, red ink, stamps, camera drift, glitch titles, vintage 2D kit, local transcription.
